Kebijakan Privasi Cosmic Ludo

Terakhir diperbarui: 13 November 2026

1. Pengantar

Cosmic Ludo ("Kami") menghargai privasi Anda. Dokumen ini menjelaskan bagaimana Kami mengumpulkan, menggunakan, dan melindungi data Anda saat menggunakan aplikasi Cosmic Ludo ("Aplikasi").

2. Data yang Kami Kumpulkan

Aplikasi ini mengumpulkan data berikut:

2.1. Data Akun

  • ID Pengguna (User ID): Identifikasi unik yang dihasilkan secara otomatis saat Anda masuk ke Aplikasi (melalui autentikasi anonim Supabase). ID ini digunakan untuk:
    • Mengidentifikasi Anda dalam pertandingan multiplayer.
    • Menyimpan progres permainan lokal.
  • Nama Panggilan (Nickname): Nama yang Anda pilih untuk profil dalam Aplikasi. Nama ini hanya ditampilkan di layar profil dan tidak dikaitkan dengan identitas nyata Anda.

2.2. Data Permainan

  • Data Multiplayer: Saat Anda bermain mode online, Kami menyimpan:
    • Riwayat pertandingan (hasil menang/kalah).
    • Statistik permainan (jumlah langkah, skor, dll).
  • Data ini disimpan di server cloud (Supabase) dan digunakan untuk:
    • Sinkronisasi antar pemain dalam pertandingan online.
    • Menampilkan leaderboard/peringkat global (jika fitur tersedia).

2.3. Data Teknis

  • Log Crash: Kami dapat mengumpulkan log crash secara otomatis untuk memperbaiki bug dan stabilitas Aplikasi. Log ini tidak berisi informasi pribadi Anda.

3. Cara Kami Menggunakan Data Anda

Kami menggunakan data yang dikumpulkan untuk:

  • Menjalankan dan menyediakan fitur Aplikasi (misalnya matchmaking online).
  • Meningkatkan kualitas Aplikasi (melalui analisis crash dan bug).
  • Menampilkan profil Anda kepada pemain lain dalam pertandingan online.

4. Penyimpanan Data

  • Data Anda disimpan di server cloud yang dioperasikan oleh Supabase (penyedia layanan database).
  • Kami tidak menjual data Anda kepada pihak ketiga.
  • Kami tidak mengungkapkan data Anda kepada pihak ketiga, kecuali jika diwajibkan oleh hukum.

5. Keamanan Data

Kami menerapkan langkah-langkah keamanan yang wajar untuk melindungi data Anda, termasuk:

  • Enkripsi komunikasi antara Aplikasi dan server (HTTPS).
  • Kontrol akses yang ketat terhadap database.
  • Namun, tidak ada metode transmisi atau penyimpanan data yang 100% aman. Kami tidak dapat menjamin keamanan absolut.

6. Hak Anda

Anda memiliki hak untuk:

  • Mengakses data Anda yang Kami simpan.
  • Meminta penghapusan data Anda (dengan menghapus akun melalui Aplikasi atau menghubungi Kami).
  • Menarik persetujuan Anda untuk pengumpulan data.

Untuk melaksanakan hak ini, Anda dapat menghubungi Kami di alamat email di bawah.

7. Data Anak-Anak

Aplikasi ini ditujukan untuk pengguna berusia 7 tahun ke atas. Kami tidak sengaja mengumpulkan data pribadi dari anak di bawah 13 tahun tanpa persetujuan orang tua. Jika Kami mengetahui bahwa Kami telah mengumpulkan data dari anak di bawah 13 tahun tanpa persetujuan orang tua, Kami akan mengambil langkah untuk menghapus data tersebut.

8. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Perubahan akan diposting di halaman ini dengan tanggal revisi terbaru. Kami menyarankan Anda meninjau Kebijakan Privasi ini secara berkala.
